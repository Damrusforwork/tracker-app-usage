# TRACE — App Usage Journal

Android-first, on-device app for reviewing which apps you open, when, and for how long.
All usage data is processed and stored locally — no account, no cloud sync.

## Features

- **Today** — total time, app count, launches, average per launch, top apps, 7-day sparkline, category breakdown, daily insight, yesterday delta.
- **Apps** — search, sort, category filter, per-app detail with trend and sessions.
- **History** — grouped by day then hour; tap a block to expand its sessions.
- **Calendar** — month grid + day detail + 24h timeline.
- **Settings** — Usage Access shortcut, dark mode (system/light/dark), daily notification, data retention (7/30/90/unlimited), TH/EN language, debug screen.
- Native Android module reads `UsageStatsManager`, pairs foreground/background events into sessions, and subtracts screen-off intervals.

## Tech stack

- Expo / React Native (new architecture, Hermes) + TypeScript
- `react-native-safe-area-context`, `@react-native-async-storage/async-storage`, `@expo/vector-icons`
- Custom Kotlin module (`UsageAccessModule`, `UsageAccessPackage`) using `PACKAGE_USAGE_STATS`

## Project layout

```text
App.tsx                 UI: tabs, screens, overlays
index.ts                entry (registerRootComponent)
lib/usage.ts            model, storage, merge/coalesce, formatting
lib/categories.ts       app -> category mapping
lib/prefs.ts            persisted preferences (theme, retention, language)
android/                generated by Expo CNG (Kotlin module, manifest, Gradle)
```

> `android/` and `ios/` are generated (Continuous Native Generation). Never edit native
> folders by hand — configure native behavior via `app.json` and config plugins.

## Requirements

- Node 22+ and pnpm 11+
- JDK 17 (`JAVA_HOME`)
- Android SDK (Android Studio) + NDK 27 + CMake
- A physical Android device with USB debugging enabled

## Setup

```bash
pnpm install
```

`pnpm-workspace.yaml` sets `nodeLinker: hoisted`, required on Windows so native build
paths stay under the 260-char `MAX_PATH` limit.

## Run

```bash
pnpm expo start         # Metro only — use for JS-only changes
pnpm android            # build native + install + launch on the connected device
pnpm typecheck          # tsc --noEmit
pnpm test               # vitest
```

## Build a shareable release APK

```bash
cd android
./gradlew assembleRelease
```

- Output: `android/app/build/outputs/apk/release/app-release.apk`
- A copy is placed at `APK/TRACE-<version>.apk`
- The release build bundles the JS bundle, so it runs standalone (no Metro).

Install on a device:

```bash
adb install -r APK/TRACE-1.0.1.apk
# or: adb push APK/TRACE-1.0.1.apk /sdcard/Download/  then tap it on the phone
```

Release builds are currently signed with the debug keystore — fine for sideloading,
not for Play Store distribution.

## Windows build notes

- Use **JDK 17**; the JDK bundled with recent Android Studio (JBR 25) breaks the CMake/native step.
- Long native object paths: enable Windows `LongPathsEnabled` and use **Ninja >= 1.12**
  (wired via `-DCMAKE_MAKE_PROGRAM` in `android/app/build.gradle`).
- `reactNativeArchitectures=arm64-v8a` is set in `android/gradle.properties` to keep
  native builds fast on arm64 phones.

## Versioning

Bump `versionName` / `versionCode` in `android/app/build.gradle` and `version` in
`app.json` and `package.json`.
