Project Overview

TRACE — App Usage Journal

แอป Android-first สำหรับดูว่าแต่ละวันเปิดแอปอะไร เปิดกี่ครั้ง เมื่อไร และใช้นานเท่าไร — ประมวลผลและเก็บข้อมูลบนเครื่องเท่านั้น

Expo / React Native TypeScript Kotlin Native Module Android-first On-device / No cloud

1. โปรเจกต์นี้เกี่ยวกับอะไร

TRACE อ่านข้อมูลการใช้งานแอปจาก Android โดยตรงผ่าน UsageStatsManager แล้วแปลงเป็น "session" (ช่วงเวลาที่เปิดแอป) เพื่อให้ผู้ใช้ย้อนดูพฤติกรรมการใช้โทรศัพท์ของตัวเอง

  • ไม่ใช่ time tracker แม่นยำระดับวินาที — duration เป็นค่าประมาณจาก foreground/background events
  • ไม่อ่าน เนื้อหาหน้าจอ ข้อความ หรือการกดภายในแอปอื่น
  • ไม่ส่ง ข้อมูลขึ้น cloud/server — ไม่มี login ใน MVP
  • ข้อมูลเป็นข้อมูลส่วนบุคคล ควรมี privacy policy ก่อนเผยแพร่

หน้าตั้งค่า
Dark mode / แจ้งเตือนรายวัน / retention / TH-EN / debug / เปิด Usage Access
  • Delta sync — จำ lastSync อ่านเฉพาะ event ใหม่ (overlap 60 วินาที, ย้อนสูงสุด 7 วัน) แล้ว upsert ตาม session id
  • Refresh — ดึงทุก tab ได้ (ปุ่ม + pull-to-refresh), กันกดซ้ำ, ยกเลิกได้เมื่อ unmount
  • Persistence — เก็บด้วย AsyncStorage + prune ตาม retention (7/30/90/ไม่จำกัด), เปิดแอปใหม่ข้อมูลยังอยู่
  • Export / Import / Clear — ตัดออกแล้ว (ไม่มีในแอปปัจจุบัน)

3. สถาปัตยกรรม

แอปชั้นเดียว (client only) ไม่มี backend ไม่มี network call สำหรับข้อมูลการใช้งาน

index.ts  →  registerRootComponent(App)
App.tsx   →  UI 5 tabs + navigation state + load / refresh / prefs / notifications
│
├─ lib/usage.ts        →  model, repo, merge/coalesce, lastSync, date & duration utils (+ vitest)
├─ lib/usageBridge.ts  →  JS bridge ไป native module (Android เท่านั้น)
├─ lib/categories.ts   →  หมวดแอป (Social/Games/Work/Other) + day helpers
└─ lib/prefs.ts        →  theme/lang/retention/notify prefs + ชุดข้อความ TH-EN
        │
        └─ android/.../UsageAccessModule.kt   →  query UsageStatsManager, pairing+coalesce,
                                                  allowlist, หักเวลาจอดับ, เปิด Settings
           android/.../UsageAccessPackage.kt  →  register native module
           android/.../MainApplication.kt     →  เพิ่ม package เข้า package list
           android/.../AndroidManifest.xml    →  PACKAGE_USAGE_STATS + launcher queries

โครงสร้างข้อมูล Session

type UsageSession = {
  id: string;             // "<package>-<startMillis>-<endMillis>"
  packageName: string;
  appName: string;
  startedAt: string;      // ISO 8601
  endedAt: string;        // ISO 8601
  durationSeconds: number;
};

6. ข้อจำกัดที่รู้อยู่

  • Android บางรุ่นหน่วง/จำกัด UsageEvents ความแม่นยำต่างกัน
  • เวลาปิดจอถูกหักออกจาก duration ใน native แล้ว — session ข้ามเที่ยงคืนยังนับรวมในวันเริ่มต้น
  • Session ที่ยังเปิดอยู่ถูกปิดตอน refresh อาจขยับเมื่อ refresh ถี่
  • ไม่มี Export/Import — ข้อมูลอยู่บนเครื่องเท่านั้น ลบได้เฉพาะเปลี่ยน retention
  • Path build native ต้องใช้ Android SDK / Gradle (ไม่มีใน sandbox)
