06 Calendar Dashboard — Design Spec

รายละเอียด UI สำหรับ implement

🎨 Layout

  1. Header bar: month name + prev/next/today buttons
  2. Calendar grid: 7 columns (Sun–Sat), rows = weeks of month
  3. Each day cell:
    • Day number (top-left)
    • Total time badge (e.g. "2h 15m") — green text
    • App count (e.g. "8 apps") — muted text
    • Progress bar 4px — fill = % of max day in month
    • Today: green border; Selected: green bg + white text
    • Empty: no bg, no hover
  4. Detail panel (slides in below calendar on click):
    • Green header: date + total time / app count / session count
    • App list: avatar (color-coded by category) + name + launches + duration + bar
    • Bar = % of max app time that day
    • App colors: Social=#e74c3c, Games=#9b59b6, Productivity=#3498db, Other=#95a5a6

⚙ Data Requirements

  1. loadSessions() → ได้ UsageSession[] ทั้งหมด
  2. Group by date → สร้าง calendar data
  3. Per day: totalSeconds, appCount, sessionCount, topApps[]
  4. Per app in day: name, launches, totalSeconds, sessions[]
  5. Category mapping: packageName → category (local map หรือ manual)

🚀 Implementation Notes

  1. ใช้ RN Animated + useNativeDriver สำหรับ transition
  2. Calendar grid: FlatList หรือ View 7-column grid
  3. Day cell: Pressable + scale feedback
  4. Detail panel: Animated.View height 0→auto, opacity 0→1
  5. App bars: Animated.View width 0→% (GPU rule: scaleX + translateX)
  6. Category colors: local Map, no new dep
  7. Add to tab nav: "today | apps | calendar | history | settings"
